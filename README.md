# 🎯 Random Quote Generator

A simple and clean **Random Quote Generator** mobile application built with **Flutter and Dart**. The app displays an inspirational quote with its author and allows users to generate a new random quote with a single tap.

## 📱 Features

* 🎲 Random quote displayed when the app opens
* 🔄 **New Quote** button to generate another quote
* ✍️ Displays quote text and author name clearly
* 🎨 Clean and minimal user interface
* 📱 Responsive Flutter UI
* ⚡ Lightweight and fast
* 🌐 Works completely offline
* 📦 No external APIs or packages required

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

Open the project in **Android Studio** or **Visual Studio Code**.

### 3. Install Dependencies

Run:

```bash
flutter pub get
```

### 4. Run the Application

Connect an Android device/emulator and run:

```bash
flutter run
```
